# Food-Operating-System
User Authentication: Secure Sign-Up and Login system for customers.
Open the .cpp file in any standard C++ IDE (like Dev-C++ or VS Code), compile, and run.
Customer Cart: Allows users to browse the menu, add items to a cart, apply discounts, and place orders.
Admin Panel: Gives authorized access to manage food items, update prices, and view customer records.
Structures & Arrays: To organize and store menu items and customer data.
File Handling: To permanently save user credentials and order history in .txt files.
Functions & Control Flow: Uses loops, if-else statements, and modular functions for clean and reusable code.
